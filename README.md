# Ordinary Animals of São Paulo

A short field companion to the everyday birds and mammals of the USP campus, in São Paulo. Each species is shown with a photo, its popular names in Portuguese and English, its scientific name, and a short text.

The initial idea was for it to be a resource for the incoming Econet 2027.

**Live page:** [https://gus-nc.github.io/OrdinaryUSP/](https://gus-nc.github.io/OrdinaryUSP/)

## Files

- `index.html`: the page
- `images/`: the photos
